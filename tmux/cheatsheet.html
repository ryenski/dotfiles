⌨ Tmux Cheat Sheet

~/dotfiles/tmux  ·  Catppuccin / omerxx-based config

Prefix = Ctrl + `  (backtick — not the default Ctrl+b)

Sessions

⌃` oSessionX — fuzzy session picker (zoxide mode)
⌃` SChoose session (built-in tree)
⌃` Ctrl+dDetach
⌃` *List clients
⌃` Ctrl+s / Ctrl+rResurrect save / restore (plugin default)
detach-on-destroy off — closing a session switches to another instead of exiting tmux. Continuum auto-restores on start.

Windows

⌃` nNew window
⌃` Ctrl+cNew window (starts in $HOME)
⌃` H / LPrevious / next window
⌃` Ctrl+aLast window (toggle)
⌃` wList windows
⌃` "Choose window
⌃` rRename window
Windows indexed from 1, renumbered automatically on close.

Panes

⌃` sSplit vertically (below, keeps path)
⌃` vSplit horizontally (right, keeps path)
⌃` h j k lMove between panes (vim-style)
⌃` zToggle pane zoom
⌃` , / .Resize 20 cols left / right (repeatable)
⌃` - / =Resize 7 rows down / up (repeatable)
⌃` xSwap pane down
⌃` *Toggle synchronize-panes
⌃` PToggle pane border status
⌃` pFloax floating pane (80% × 80%)

Copy Mode & Clipboard

vBegin selection (in copy mode)
yYank to system clipboard (tmux-yank)
vi mode-keys · system clipboard on · history limit 1,000,000 lines.

URL & Text Grabbing

⌃` ufzf-url — pick a URL from scrollback & open (plugin default)
⌃` Spacetmux-thumbs — hint-copy on-screen text (plugin default)
⌃` Ftmux-fzf menu (plugin default)

Misc

⌃` RReload tmux.conf
⌃` KClear screen
⌃` Ctrl+lRefresh client
⌃` :Command prompt
⌃` Ctrl+xLock server

Plugins

TPM — Plugin Manager

⌃` IInstall all plugins listed in tmux.conf
⌃` UUpdate all installed plugins
⌃` alt+uRemove plugins no longer in conf
Plugins live in ~/.config/tmux/plugins/. Run I after adding a new set -g @plugin line.

tmux-sensible

auto Applied silently at startup — no key bindings. Sets sane defaults: UTF-8, 50k history, focus events, faster key repeat, $SHELL as default command, and ensures ⌃` sends the right escape.

tmux-yank

y copy modeYank selection to system clipboard and stay in copy mode
Y copy modeYank current line to system clipboard
⌃` yYank current pane's command to clipboard
⌃` YYank current pane's working directory to clipboard
set-clipboard on — uses the system clipboard via xclip / xsel / wl-copy on Linux.

tmux-resurrect

⌃` Ctrl+sSave all sessions, windows, panes & layouts to disk
⌃` Ctrl+rRestore last saved environment
nvim strategy — neovim sessions are restored via Session.vim (requires vim-obsession or similar). Saves to ~/.local/share/tmux/resurrect/.

tmux-continuum

auto Saves the environment automatically every 15 minutes using tmux-resurrect under the hood.
@continuum-restore on — the last saved environment is restored automatically when tmux server starts. No key binding needed.

tmux-thumbs

⌃` SpaceEnter thumbs mode — overlays letter hints on matched patterns in the visible pane
a–z thumbs modeCopy match to the tmux buffer (not system clipboard) and exit
A–Z thumbs modeCopy match to tmux buffer and paste it directly into the current pane
Space thumbs modeEnter multi-select — pick multiple hints, then Space again to paste all space-separated
↑ ↓ thumbs modeArrow-navigate between matches instead of typing hint letters
Matched patterns: file paths, git SHAs, hex colors, IPv4/IPv6, UUIDs, Docker images, Kubernetes resources, URLs, numbers (4+ digits), and more. Add custom patterns with @thumbs-regexp-N.
⚠ Copies to the tmux buffer by default, not the system clipboard. Paste with ⌃` ] or set @thumbs-osc52 1 for OSC52 clipboard passthrough.

tmux-fzf

⌃` FOpen the tmux-fzf menu
Menu entries: Session — switch/new/rename/kill · Window — switch/new/rename/close · Pane — switch/swap/kill · Command — run any tmux command · Key binding — browse and trigger bindings.

tmux-fzf-url

⌃` uFuzzy-pick a URL from scrollback and open it in the browser
Searches the last 2,000 lines of scrollback. Popup is 60%×30% with label Open URL. Opens with xdg-open on Linux.

catppuccin

theme Status bar pinned to the top. Left module: session name. Right module: current directory basename.
Active window label shows a zoom indicator () when the pane is zoomed. Window numbers appear on the right side of each tab.
Uses the omerxx fork (omerxx/catppuccin-tmux) — includes a calendar/meetings script (currently commented out in conf).

tmux-sessionx

⌃` oOpen SessionX picker (fuzzy, zoxide-powered)
Ctrl+y sessionxOpen selected session in a new window instead of switching
Ctrl+d sessionxDelete the selected session
Ctrl+r sessionxRename the selected session
Tab sessionxPreview windows in the selected session
Popup is 75%×85%. Zoxide mode on — type a directory name to create or jump to a session for that path. Custom path: ~/dotfiles. Auto-accept off (press Enter to confirm).

tmux-floax

⌃` pToggle the floating pane open / closed
Floating pane is 80%×80% with a magenta border and blue text. change-path true — the floating pane inherits the current pane's working directory each time it opens.

Gotchas

escape-time 0 — no Esc delay (good for vim).
SessionX custom path is set to ~/dotfiles (@sessionx-custom-paths-subdirectories false).
